# Sanitized Unity test evidence

These are sanitized copies, not original logs. All eight original files remain unchanged in local Reports; they are not uploaded. `manifest.json` records their hashes, copy hashes and exact redaction policy. Files use deterministic gzip compression; decompress with `gzip -dc <file.gz>`. Test names, outcomes and totals are preserved.

Scope: exact fork 093a175b60a196e2ad864a01ace49e90f58aacc3, Unity 6000.6.5f1; consumer EditMode 3/3, PlayMode 5/5, focused native physics 7/7. The failed-cache dependency log is an unsuccessful attempt, not test evidence. Headless results do not validate rendered graphics, audio playback or a new Player.
